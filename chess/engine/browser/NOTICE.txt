KNIGHT SCHOOL - BUNDLED BROWSER ENGINES

These are real, independent, single-thread WebAssembly engines. They run in
owned Workers over UCI; no remote engine server or SharedArrayBuffer is needed.
Only the selected engine's runtime/network downloads during normal use.

REPRODUCING / DEPLOYING
In the Knight School source checkout, install the pinned npm dependencies,
then run: npm run source:browser-engines --workspace @knight-school/web
That explicitly downloads the pinned port artifacts, verifies every size and
SHA-256, preserves their source archives and builds the Worker adapter.
Normal dev/build/export only verify local assets; they never silently download.
Keep this entire directory in the uploaded chess/ folder, including sources
and license texts. Do not remove the large source archives to reduce ZIP size.
Engine programs remain independent UCI modules; no commercial engine weights,
native executables, credentials or bridge tokens are bundled.
